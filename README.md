# Domain-Specific FAQ Chatbot

A chatbot that answers questions within a specific domain, using AI-generated responses backed by keyword-based search.

## Feature Set C

- **Domain-specific FAQ chatbot**: answers questions focused on a single subject area.
- **AI-generated responses**: produces natural, context-aware answers.
- **Keyword-based search**: finds relevant FAQ entries by matching keywords.
- **Conversation history**: keeps past messages so users can review earlier exchanges.
- **Suggested questions**: offers quick-start and follow-up questions to guide users.

## Getting Started

```bash
# 1. Clone the repository
git clone https://github.com/sonalighatage/ChatBot.git
cd ChatBot

# 2. Install dependencies
# No dependencies needed! The app is purely frontend HTML/JS/CSS.

# 3. Run the app
# Simply open index.html in your web browser. 
# For example, on Windows you can type:
start index.html
```

## Usage

1. Open the chatbot (`index.html`).
2. Type a question or pick one of the suggested questions.
3. Read the AI-generated answer.
4. Scroll back through the conversation history at any time.

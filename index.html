About This Project

Project

College AI Assistant — Feature Set C is a college mini-project demonstrating a conversational assistant that helps students find information about everyday academic matters quickly and clearly.

Purpose

Students often have simple, repetitive questions — attendance, fees, exam dates, assignment submission — that are scattered across notices and offices. This assistant brings answers into one simple chat interface, understands different phrasings of the same question, and is honest when it doesn't know something.

How it works

  • A local knowledge base covers ten core college topics with multiple sample question phrasings each.
  • An intent-matching engine scores your message against known question patterns and keywords to find the closest match.
  • Short conversational context (like "what about it?" after a topic) is remembered within the current chat.
  • If confidence is too low, the assistant gives an honest fallback message instead of guessing.
  • An optional configuration panel allows connecting a real AI API key (kept in the browser only) for richer generated answers.

Tech stack

Built with plain HTML, CSS and JavaScript — no frameworks or servers required. Conversation history is saved with the browser's localStorage.
